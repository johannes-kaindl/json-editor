# JSON Editor — documentation

Organised after [Diátaxis](https://diataxis.fr/): learning something and fixing something are different needs, so they live on different pages. Only the kinds that have content are listed here.

**New here?** → [Getting started](getting-started.md) — from the install to your first edited `.json` file.

**Something not working?** → [Troubleshooting](troubleshooting.md) — the exact message you see, what it means, what to do.

| | |
|---|---|
| **[Getting started](getting-started.md)** | Learning-oriented. Open a `.json` file, edit it in the tree, switch to source, try a `.jsonc` file and a code block in a note. |
| **[Troubleshooting](troubleshooting.md)** | Task-oriented. "Invalid JSON at line …", "Large file — opened in Source mode", "another plugin already handles .json", the repair messages. |

The [README](https://github.com/johannes-kaindl/json-editor/blob/main/README.md) covers what the plugin does, how to install it, every setting and the LLM repair.
